# Mystery Emblem — Low-Token Architecture Map

Read this index first in every session before scanning directories. Read only the 1–2 files relevant to your task.

## 1. Core Architectural Invariants (`GEMINI.md`)
- **Manual Balance Only:** Never compute stats/growths from PokéAPI; read human-editable sharded JSON registries via `src/mystery-emblem/data/index.ts`.
- **Unified Pointer Events Only:** `pointerdown`/`pointermove`/`pointerup` (`src/mystery-emblem/ui/pointerControls.ts`); zero keyboard bindings; `>=44px` mobile hitboxes; persistent corner `Menu`/`Back` + long-press parity.
- **Tactical Combat Rules:** 4-move loadout; `Physical` = Range 1, `Special` = Range 2, `Support/Heal` = Range 1 or 1–2 (`heal`/`self_heal`/`status`/`shield`/`dance`); dual `[E]` slots (one Physical + one Special, `data/equippedMoves.ts`) counter on Enemy Phase by range; zero pure stat-boost moves.
- **Strict Faction & Lv. 1–40 Curve:** `playable`, `enemy`, `convertible` (`gastly_line`, `sandile_line`, `seedot_line`), and `ally_npc` (`kecleon_line`) enforced by `campaignConfig.ts` & `registryValidators.ts`; Stone promotions Lv. 10+ (Lv. 15 `eevee`/`wimpod`), Gem Lv. 20+.
- **Pixel Rendering:** `imageSmoothingEnabled = false` + `image-rendering: pixelated`; `1x` native `24x24`px buffer + CSS scale (`ui/gridViewportMath.ts`); sprite footline `(frameW/2, frameH/2 + 4)` anchored at `(12, 20)`.
- **Hybrid Cloud Save:** Immediate `localStorage` (`mystery_emblem_save_v1`, `mystery_emblem_map_overrides_v1`) + Firebase Auth/Firestore (`saves/{uid}`, flat `customMapsEnvelopeJson`, `lastUpdated` timestamp resolution; `signInWithPopup` bound strictly to `click`).
- **Verification Gate:** Always run `npm run typecheck && npm run build && npm test` (`playwright.config.ts` serves `dist/`).

### Data, Sharded Registries & Self-Contained Chapters (`src/mystery-emblem/data/`)
- `campaignConfig.ts` — Central campaign rules (`MIN_UNIT_LEVEL=1`, `MAX_UNIT_LEVEL=40`, promotion levels, `MENTOR_JAGEN_SPECIES_ID='sir_empoleon'`, `ADVISOR_EVOLVED_SPECIES_ID`, `DRAGON_LORD_SPECIES_IDS`, `CONVERTIBLE_FACTION_LINE_IDS`, `ACT1_CREDITS_NODE_ID='chapter_06'`, `INITIAL_CAMPAIGN_CONVOY`, `DEFAULT_QUIZ_SEEDS`, `formatCampaignChapterLabel`, `formatCampaignShortCode`).
- `index.ts` — Hydrates sharded JSONs into O(1) maps & getters: `getSpeciesById`, `getMoveById`, `getItemById`, `getPersonalSkillById`, `getSpeciesLine`, `getRegistryValidationSummary`.
- `species/{line_learnsets,playable_core,playable_story,playable_quiz_early,playable_quiz_late,playable_paralogues,enemies_commonwealth_sand,enemies_empire_abyss}.json` — 183 Lore-Bible species across 64 lines (incl. Stage 3 Jagen `sir_empoleon` & `Levitate` `duskull_line`) + family-shared learnsets/TM compatibility.
- `moves/{physical,special,support}.json`, `items/{consumables_and_vitamins,held_items,tms}.json`, `personal_skills.json` — Manual moves (incl. `will_o_wisp`/`thunder_wave`/`toxic`/`hypnosis` `status` hexes & `feather_dance_step` `dance`), items, TMs, and personal skills.
- `chapters/{prologue,chapter_01..06,paralogue_01..02}/{chapter.json,dialogue/*.json}` — Self-contained per-chapter compact tile rows, `playerSpawns`/`npcSpawns`/`enemySpawns` (w/ `seedKey` quiz-slot resolution), `reinforcements`, declarative `events`, pre/post story cutscene IDs, and battle dialogue JSON (`intro.json`, `outro.json`, event dialogues referenced by `play_dialogue.scriptId`). The Prologue is a scripted sparring drill (`prologue/tutorialStaging.ts`): Turn 1 rests all but the lord (`rest_player_units`) and forces its move to one tile inside Sir Empoleon's real reach; Sir Empoleon (a `sparring` spawn: always hits, no crits, nobody drops below 1 HP, only Peck `[E]` via `equippedMoveIds`) advances and strikes the lord on Enemy Phase 1; Turn 2 rests the partner and auto-plays the `prologueDrillTopics.ts` drills (select healer → tap lord → Heal, then move the lord to a forced Range-2 tile and Dragon Breath with no counter); ending Turn 2 starts the ambush. The generic `ch1_first_combat_forecast` / `ch1_healing_and_items` topics are suppressed during the Prologue. `move_unit` and `unit_healed` are also available for scripted events.
- `chapters/{chapterTypes,chapterCodec,mapValidator,defaultCatalog,index}.ts` & `mapOverrideStore.ts` — Chapter hydration (`applyEditedChapterJson` hot-applies editor saves), map/event/reinforcement validator, and custom map override store (keeps retired `cutscene_stage_*` browser edits so the Cutscene Editor can offer to import them) (`campaignRegistry.ts` & `chapterMapRegistry.ts` barrels).
- `cutscenes/{*.json,locations/*.json}` + `cutscenes/{cutsceneDocTypes,cutsceneRegistry,dialogueCompiler,locationCodec,mediaLibrary,previewSave}.ts` — Editor-authored story cutscenes (cast, starting placements, beats = optional line + stage actions + show-if/music/sound) and shared locations (layer stacks: `tiles`/`picture`/`texture`/`parallax`, behind or in front of characters); auto-discovered registry, cast → speaker resolution, show-if, auto sides, `{name:castId}` tokens; media from `assets/{cutscene-backgrounds,cutscene-props,sfx}/`.
- `jsonFormat.ts` — `formatProjectJson` (compact readable JSON) and `formatChapterJson` (chapter.json house style) for editor writes.
- `quizLordProfiles.ts`, `quizQuestions.ts` (`quizData.ts` barrel) — 5 Dragon Lord aura profiles & 8-question Lore-Bible personality quiz (`slot1Flying`..`slot8Ice`).
- `overworld/{overworldGraphData,kecleonShopCatalog,skirmishEncounterData}.ts` (`overworldMapData.ts` barrel) — 9-node Part 1A Wonder Map graph (`Prologue`–`Ch. 6` + `Paralogues 1–2`), 4 Kecleon Shop stock catalogs (milestone-gating Stones/Gems), Feral Skirmish layouts & scout builds.
- `storyCutscenes.ts`, `creditsData.ts`, `accessControl.ts`, `allegiance.ts` — cutscene lookup + chapter links (`getPre/PostChapterCutsceneId`, `listStoryCutscenesInPlayOrder`), parameterized credits metadata (`King Serperior`, `Lady Milotic`, `Sir Empoleon`, Wimpod/Golisopod deduplication), admin gate (always unlocked on `localhost`), unit-card kingdom allegiance by species line (`Feral`-nicknamed enemies -> `Feral`).
- `tutorials/{tutorialTypes,earlyChapterTopics,mechanicsAndTerrainTopics,tutorialTriggers}.ts` (`tutorialRegistry.ts` barrel) — 16 Wimpod coaching topics (incl. `talk_recruitment` & `levitate_and_status`) & declarative `TUTORIAL_TRIGGER_RULES`. During the Prologue fight `triggerBattleTutorial` passes `presenter: 'mentor'`, so Sir Empoleon voices the card using optional per-beat `mentorDialogue` / `mentorEmotion`; "Ask Wimpod" replays always use Wimpod.
